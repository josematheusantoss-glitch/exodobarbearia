# Êxodo Barbearia

Página institucional e prévia interativa do agendamento da Êxodo Barbearia. O agendamento fica em `agendamento.html`, separado da página inicial. A identidade visual compartilhada fica em `premium.css`.

## Prévia do agendamento

O frontend permite selecionar serviços, visualizar o total, escolher profissional, data e horário ilustrativos, preencher dados e revisar o resumo. **Nenhuma reserva é registrada nesta versão.** O botão de confirmação permanece indisponível até a integração com agenda e banco de dados.

Valores, duração provisória dos serviços, profissionais e horários ilustrativos estão em `booking-config.js`. Ajuste esses dados antes de ativar reservas reais. Não há envio automático de WhatsApp nesta versão.

Abra `index.html` no navegador para visualizar localmente. O deploy de produção está em https://exodobarbearia.vercel.app/.
